# Minuteurs d'examen — Haut-Lac

Application web progressive (PWA) de minuteurs multi-examens pour Haut-Lac International School.

### 1. Installer sur iPad / iPhone

1. Ouvrez l'URL dans **Safari** (pas Chrome — seul Safari permet l'installation sur iOS)
2. Appuyez sur le bouton **Partager** (carré avec flèche vers le haut)
3. Faites défiler et appuyez **Sur l'écran d'accueil**
4. Appuyez **Ajouter**

L'app apparaît sur l'écran d'accueil comme une vraie application, s'ouvre en plein écran sans barre Safari, et fonctionne hors ligne.

On peut lancer plusieurs examens, avec des options pour le temps supplémentaire (on peut écrire dessus pour changer, et même mettre des fractions comme taper 1/3 où le défaut est 25% et cela fera un tiers du temps supplémentaire). On peut mettre deux alertes pour (par défaut, réglable) 30 minutes et 5 minutes avant la fin. Pour l'instant, le signal sonore automatique ne marche pas sur iOS à cause des restrictions du système (le son est coupé sans interaction par l'utilisateur) mais les minuteurs changent de couleur.

Il faut juste changer le logo en remplaçant par un fichier de votre choix (Haut-Lac-logo.svg).
